SkillSwap: Peer-to-Peer Learning MarketplaceSkillSwap is a community-driven digital transformation platform where users trade knowledge directly with one another. By leveraging a reciprocal economy, users can teach skills they master in exchange for learning new ones, using a virtual "Skill Coin" currency.🚀 Key Features🔐 Secure AuthenticationJWT & HttpOnly Cookies: Implements a stateless security model using JSON Web Tokens. Tokens are stored in HttpOnly cookies to provide robust defense against XSS attacks.Spring Security: Managed via a custom filter chain that enforces Role-Based Access Control (RBAC).🤝 The Swap EcosystemSwap Request System: A formal "handshake" protocol (Pending, Accepted, Rejected) for negotiating skill trades.Session Scheduling: Automated session creation upon request acceptance, featuring a state-machine (Upcoming, In-Progress, Completed) to track learning progress.Real-Time Messaging: Bidirectional chat built on WebSockets, allowing users to coordinate sessions instantly.💰 Gamified EconomyCoin Reward System: Users earn 50 Skill Coins upon the successful completion of a session. This ensures a "Proof of Work" loop that keeps the marketplace active.Store & Inventory: A virtual marketplace where earned coins can be spent on profile customization (Frames, Badges) and utility items.🛠 Administrative ControlAdmin Dashboard: A restricted oversight panel for monitoring platform statistics, managing users, and moderating content.🎨 Modern UI/UXDark Mode: A persistent, professional aesthetic implemented via CSS variables and localStorage to reduce eye strain.Notifications: An event-driven system that alerts users to new requests, messages, and payouts.🛠 Tech StackLayerTechnologyBackendJava, Spring Boot, Spring SecurityDatabaseMySQL, Hibernate/JPAFrontendHTML5, CSS3, JavaScript (Vanilla)SecurityJWT (JSON Web Tokens)CommunicationWebSockets (STOMP/SockJS)MailSpring Boot Starter Mail (SMTP)📦 Installation & SetupClone the repositoryBashgit clone https://github.com/yourusername/skillswap.git
